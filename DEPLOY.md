# DEPLOY — Дашборд «продюсеры»

## Состав
- Фронт: этот репозиторий (GitHub Pages, ветка main, корень). Адрес: https://drakon040537-del.github.io/pd/
- Сервер: Apps Script (Расширения таблицы «продюсеры» → Apps Script). Канонический код — файл apps-script-vNN.gs в bionicпамять/память/дашборд-продюсеры/.
- Данные: приватная Google-Таблица «продюсеры» (канон данных). Схема листов команд: «Компания (дд-дд.мм)», колонки A..U (см. ПАМЯТКА-ПРОЕКТА.md).

## Деплой фронтенда
1. Заменить index.html в корне репозитория (PWA-файлы: manifest.webmanifest, sw.js, icon-192.png, icon-512.png — лежат рядом).
2. Commit → push в main. Pages соберётся сам (иногда падает разово — пустой коммит перезапускает сборку).
3. Проверить адрес без параметров: вход логином и паролем.

## Деплой сервера (Apps Script)
1. Расширения таблицы → Apps Script → заменить код целиком (канон — apps-script-vNN.gs).
2. **Управление развертываниями → ✏️ → «Новая версия»** (URL не менять; доступ «Все»).
3. Права на Диск (критично для скринов): после вставки кода выбрать любую функцию → «Выполнить» → окно разрешений → Разрешить (должен быть пункт Google Диск).
4. Проверить маркер версии: ответ authpoll/check содержит "v":NN.

## Доступ (пользователи)
- Логины + хэши паролей: Script Properties → USERS_JSON (формат: [{"u","h":"соль$хэш","name","edit","cities","prod"}]). Соль внутри каждого пользователя; отдельный PWSALT — легаси.
- Смена пароля: заявка на сайте → одобрение редактором → одноразовый код 15 мин → смена. Пароли хранятся только хэшами.

## Важно
- Запись разрешена только в листы «Компания (дд-дд.мм)» и служебные (Цвета, Планы, Чек, Рекомендации, Скрины, Сбросы, Предложения, Итог, Задачи). Листы расписания и дохода — только чтение (FORBIDDEN_SHEETS).
- При смене схемы колонок менять сервер (FIELDS/readPayload_/ensureServiceColumns_) и фронт (CATS/FIELDCODES) одновременно.
