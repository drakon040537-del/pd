## 2026-10-09 — Обновление 7: новый дизайн (VER 2026-10-09.71)
- Две темы: тёмная и светлая (+ «как в системе»), переключатель в верхней панели и в меню профиля; выбор запоминается.
- Верхняя панель: неделя, статус «обновлено», уведомления, «＋ Мониторинг», меню профиля (пароль, предложение, новая неделя, режим планёрки, «глазами», «Выйти»).
- Вход: без названий компаний, встряхивание при ошибке.
- Левое меню: значки вместо эмодзи, цвета студий, заголовок страницы = открытый раздел.
- Карточка команды: категории строками, «✓ Норма / ✕ Замечание», большое растущее поле комментария, счётчик символов, «⤢ развернуть» на весь экран с переходом по категориям.
- ИИ: меню по группам, «ИИ думает» скелетоном, полоса хода у «ИИ по компании».
- Анимации: появление разделов, набегающие цифры, рост полос; отключаются при «уменьшить движение».
- Логика, запросы к серверу и права не менялись. Сервер (Apps Script) обновлять не нужно.

## 2026-10-05 — Обновления 1–5 (VER 2026-10-05.28–.40)
- Безопасность: вход по токену сессии (пароль не в адресе запроса и не в localStorage), пользователи и хэши паролей в Script Properties, все операции через POST, белый список записываемых листов, чтение ничего не меняет, notFormula экранирует = + - @, aipoll с проверкой владельца.
- Экран: города → компании (ArtLife / VVCAM / DIAMOND — только отображение), шкала оценки 0–8, счётчики по командам, «Мои задачи» продюсеров, черновик проверки с восстановлением, вкладка «Итог», оптимистичное сохранение с авто-повтором и «повторить» при ошибке.
- ИИ (Gemini, ключ на сервере): «что горит», «сгруппировать замечания», «полный разбор», «сравнить с прошлой неделей», «совет оператору», «тон комментария», смысловой поиск по всем командам, подтверждение перед любой записью.
- Инфра: tolerant JSON parse (Google echo отдаёт сырые переводы строк внутри строк), таймаут чтения 120с с авто-повтором, кэш Gemini 10 минут.
